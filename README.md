# Teensy Web Controller

Teensy 4.1 に .hex を書き込み、シリアル通信でコマンドを送って制御する Web アプリです。
プログラム（.ino / .h / .hex）はサイトには置かず、PC 内のフォルダから読み込みます。

仕様の詳細は [SPEC.md](SPEC.md) を参照してください。

## 動作環境

- **Microsoft Edge（最新版）**。フォルダの読み書き（File System Access API）、Web Serial、WebHID を使うため、Firefox や Safari では動きません。
- Teensy 4.1 を 1 台。Arduino IDE の「USB Type」に **Serial を含む設定** でコンパイルしてください（コマンドの受信と、書き込み前の自動リブートに使います）。

## フォルダ構成

```
ルートフォルダ/                 ← サイトで「フォルダ選択」するフォルダ
├─ teensy_web.json             ← 設定（サイトが自動で作成・更新）
├─ ProjectA/
│   ├─ ProjectA.ino
│   ├─ xxx.h
│   └─ ProjectA.ino.hex        ← Arduino IDE で書き出した .hex を置く
└─ ProjectB/
    ├─ ProjectB.ino
    └─ ProjectB.ino.hex
```

## 使い方

1. **.hex を用意する**
   Arduino IDE で「スケッチ」→「コンパイルしたバイナリをエクスポート」を実行します。
   Arduino IDE 2 では `スケッチのフォルダ/build/teensy.avr.teensy41/` に .hex ができるので、.ino と同じフォルダにコピーします。
2. **フォルダを選ぶ**
   サイトを開き、上のバーの「フォルダ選択」でルートフォルダを選びます。ファイルの編集を許可するか聞かれたら「許可」を選んでください。
   次回からは「前回のフォルダを開く」を押すだけで開けます。
3. **プログラムを登録する**
   「＋ プログラムを追加」で .hex を選ぶと登録され、編集モードになります。
   プログラム名・説明・コマンドボタン（コマンドと説明）を入力し、「編集を終了して保存」を押すと `teensy_web.json` に保存されます。
4. **シリアルに接続する**
   「ポート追加」で Teensy を選び、「接続」を押します。
5. **書き込む**
   プログラムの「書き込み」を押します。
   初回は「Teensy を選択」の案内が出るので、ボタンを押して一覧の Teensy を選んで「接続」を押してください。
   書き込みが終わると、シリアルに自動で再接続します。
6. **コマンドを送る**
   コマンドボタンを押すと、そのコマンドに改行（`\n`）を付けて送ります。
   最後に書き込んだものと違うプログラムのボタンを押した場合は、確認が出ます。
   シリアルモニタ上の入力欄からは、任意のコマンドを送れます（↑↓キーで履歴）。

### 送る前に値を変えたいコマンド

編集モードでコマンドを入力するときに、変えたい部分を `{ }` で囲みます。`{ }` の中が初期値です。

```
Tx ch1 {03} {28} {00}
```

画面では `Tx ch1 [03] [28] [00] [送信]` のように入力欄つきで表示され、値を書き換えて「送信」（または Enter）で送れます。
数字でも文字でも囲めます（例: `Tx ch{1} {03}`）。`{` `}` そのものを送りたいときは `{{` `}}` と書きます。

これまでに保存した `teensy_web.json` はそのまま使えます（`{ }` を含まないコマンドは今までどおりのボタンです）。

### シリアル欄の幅

シリアル欄の左端をドラッグすると幅を変えられます。ダブルクリックで元の幅に戻ります。変えた幅はブラウザが覚えています。

## 別の PC で使う

ルートフォルダをまるごと（`teensy_web.json` と各プロジェクトフォルダ、.hex を含めて）コピーし、サイトでそのフォルダを選ぶだけです。
「最後に書き込んだプログラム」の記録は PC（ブラウザ）ごとに持ち、JSON には含めません。

## GitHub Pages で公開する

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にします。
ビルドは不要です。

## 注意

- シリアルポートの COM 番号は、ブラウザの仕様で表示できません。一覧には「Teensy（16C0:0483）」のように USB の ID を表示します。
- 書き込みでは Teensy のブートローダー（HalfKay）に WebHID で直接データを送ります。書き込み規則は PJRC の teensy_loader_cli に合わせています。
- ローカルで試すときは、`python -m http.server` などで `http://localhost` から開いてください（`file://` では一部の機能が動きません）。
